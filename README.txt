SmartQR Data Analyzer - React JS TypeScript Version

Project type:
Vite + React JS + TypeScript (.tsx)

How to run:
1. Open this project folder in VS Code.
2. Open terminal in the project folder.
3. Run: npm install
4. Run: npm run dev
5. Open the local URL shown in the terminal, usually http://localhost:5173/

Important pages included:
- Home
- Dashboard
- Scanner
- Analytics
- History
- Login / Sign In
- Signup / Register

Assignment requirements completed:
- Converted simple webpages into React JS TSX environment.
- Used React Router for navigation.
- Dashboard link is included in Navbar.
- Dashboard has view, insert, update, delete and graphical record view features.
- Login and Signup/Register pages are included.
- External CSS is used in src/index.css.
- App.css is kept empty.
- Images are placed in public/images.
- Components are placed inside src/components/ComponentName/page.tsx.
- Pages are placed inside src/pages/PageName/page.tsx.
- No Tailwind CSS is used.

Notes:
- The QR history, demo users, and dashboard records are saved in browser localStorage.
- The camera QR scanner depends on browser support. Chrome/Edge are recommended.
- The uploaded QR image scanner uses the jsqr npm package, so it does not need an online CDN.
